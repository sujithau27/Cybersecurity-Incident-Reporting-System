## Project Description

A web-based **Cybersecurity Incident Reporting System** developed using **Python Flask and MySQL**. The system allows users to securely report and manage cybersecurity incidents through a simple web-based platform.

## Technologies Used

* Python
* Flask
* MySQL
* HTML
* CSS
* XAMPP

## Main Features

* User Registration
* Secure Login
* Password Hashing
* Cybersecurity Incident Reporting
* Dashboard
* View Reports
* Edit Reports
* Delete Reports
* CRUD Operations
* MySQL Database Integration
* Session-based Authentication

## Project Purpose

This project allows users to **submit and manage cybersecurity incident reports** through a simple reporting platform. Users can report incidents such as **phishing attacks, malware, data breaches, password attacks, and network attacks**.

## CRUD Operations

* **Create** – Add a new incident
* **Read** – View reported incidents
* **Update** – Edit incident details
* **Delete** – Delete incident reports
